## ۱) تجربه‌ی کاربر نهایی

1. فایل `YouTubeDownloader-Setup-1.0.0-x64.exe` را دانلود و اجرا کنید.
   - اگر ویندوز پیام **«Windows protected your PC»** نشان داد (چون فایل امضای دیجیتال ندارد):
     روی **More info** و سپس **Run anyway** کلیک کنید.
   - نصب **برای کاربر جاری** انجام می‌شود؛ **نه دسترسی مدیر لازم است و نه پیام UAC**.
2. ویزارد نصب فارسی است (بعدی/نصب/پایان) و در پایان برنامه اجرا می‌شود.
3. از این پس با هر بار اجرای میانبر **«یوتیوب دانلودر»** از منوی استارت:
   - یک پنجره‌ی سرویس باز می‌ماند (همان پنجره = خود برنامه)،
   - مرورگر خودکار روی `http://127.0.0.1:3000` باز می‌شود،
   - لینک ویدئو را بچسبانید، «بررسی لینک» را بزنید و کیفیت ویدئو (MP4) یا بیت‌ریت MP3 را انتخاب کنید.
4. برای بستن: `Ctrl+C` در پنجره‌ی سرویس، بستن همان پنجره، یا اجرای **Stop-YouTubeDownloader.cmd**.
5. حذف برنامه: از منوی استارت → «حذف یوتیوب دانلودر» (پیش از حذف، سرویس در حال اجرا خودکار متوقف می‌شود).

هیچ پیش‌نیازی روی سیستم کاربر لازم نیست: **Node.js، yt-dlp و ffmpeg** همراه بسته نصب می‌شوند.

## ۲) معماری بسته

```
YouTubeDownloader/
├─ Start-YouTubeDownloader.cmd   اجرای سرویس + باز کردن مرورگر
├─ Stop-YouTubeDownloader.cmd    توقف سرویس و بستن yt-dlp/ffmpeg
├─ Update-yt-dlp.cmd             به‌روزرسانی yt-dlp از مخزن رسمی
├─ runner.mjs                    لانچر: خواندن .env، انتخاب پورت آزاد، لاگ، اجرای Next.js
├─ runtime/node.exe              Node.js v24.21.0 (نسخه‌ی تأییدشده روی ویندوز)
├─ tools/yt-dlp.exe              yt-dlp 2026.08.19
├─ tools/ffmpeg.exe              ffmpeg N-92722-gf22fcd4483
├─ node_modules/ · .next/ · public/   خود برنامه (نسخه‌ی production)
├─ next.config.mjs               پیکربندی زمان اجرا (کامپایل‌شده در زمان ساخت)
├─ .env.example · README.txt     تنظیمات و راهنمای فارسی
└─ data/                         downloads · cache · logs
```

نکته‌های رفتاری:

- سرور فقط روی `127.0.0.1` گوش می‌دهد؛ بنابراین **هیچ هشدار فایروال ویندوز** نمایش داده نمی‌شود و
  برنامه از بیرون قابل دسترسی نیست.
- اگر پورت ۳۰۰۰ اشغال باشد، لانچر خودکار پورت آزاد بعدی را انتخاب می‌کند و آدرس درست را چاپ می‌کند.
- اجرای دوم برنامه (وقتی سرویس از قبل بالاست) فقط مرورگر را باز می‌کند؛ سرویس تکراری اجرا نمی‌شود.
- فایل‌های خروجی در `data\downloads` ساخته و پس از پایان مهلت (پیش‌فرض ۱۲۰ دقیقه) پاک می‌شوند؛
  دانلود نهایی توسط خود مرورگر روی سیستم کاربر ذخیره می‌شود.
- تنظیمات دلخواه (کوکی، پراکسی، پوشه‌ی دانلود، تعداد دانلود هم‌زمان…) از فایل `.env` کنار برنامه خوانده می‌شود.
- محل پیش‌فرض نصب: `%LOCALAPPDATA%\YouTubeDownloader` (قابل تغییر در ویزارد، اما بهتر است در همان مسیر
  کاربری بماند تا نوشتن فایل‌ها بدون نیاز به دسترسی مدیر انجام شود).

## ۳) ساخت مجدد (برای شما یا هر مشارکت‌کننده)

**راه اول — بدون ویندوز (GitHub Actions):**

1. تب **Actions → Windows package → Run workflow** (اجرای دستی؛ بسته در بخش Artifacts همان اجرا).
2. یا push یک تگ نسخه مثل `v1.0.1`؛ بسته ساخته و **خودکار در Releases منتشر** می‌شود.

**راه دوم — روی ویندوز:**

```powershell
# پیش‌نیاز ساخت: Node.js 20+ و Inno Setup 6 (برای فایل نصب)
winget install JRSoftware.InnoSetup

# در ریشه‌ی مخزن
powershell -ExecutionPolicy Bypass -File packaging\windows\build.ps1 -Version 1.0.1 -AutoInstallInno
```

خروجی‌ها در `packaging/windows/dist/` ساخته می‌شوند. پارامترهای مفید:

| پارامتر | کاربرد |
|---|---|
| `-Version 1.0.1` | نسخه‌ی بسته (در نام فایل‌ها و VERSION.txt) |
| `-NodeVersion v24.10.0` | نسخه‌ی Node.js همراه بسته (پیش‌فرض: آخرین LTS) |
| `-Installer:$false` / `-Portable:$false` | فقط یکی از دو خروجی را بساز |
| `-SkipChecks` / `-VerifyPackage:$false` | رد کردن lint/test یا آزمون اجرای موقت سرور |
| `-Publish` | انتشار خودکار در Releases (نیازمند `gh` وارد‌شده) |

## ۴) آنچه در ساخت خودکار بررسی می‌شود

پیش از تحویل بسته، این موارد در محیط ویندوزی اجرا و تأیید می‌شوند:

1. **lint · typecheck · تست‌های واحد** (۳۳ تست) — همان بررسی‌های CI اصلی.
2. **اجرای واقعی ابزارهای بسته:** `runtime\node.exe --version`، `tools\yt-dlp.exe --version` و
   `tools\ffmpeg.exe -version` باید پاسخ دهند، وگرنه ساخت متوقف می‌شود.
3. **آزمون سرور بسته‌بندی‌شده:** سرور از داخل بسته به‌صورت موقت اجرا و پاسخ `/api/health` بررسی می‌شود
   (یعنی Node.js همراه بسته، برنامه‌ی Next.js را واقعاً بالا می‌آورد).
4. **بررسی یکپارچگی خروجی‌ها:** ZIP باز می‌شود و وجود فایل‌های کلیدی
   (`runtime\node.exe`، `tools\yt-dlp.exe`، `tools\ffmpeg.exe`، `runner.mjs`، `.next\BUILD_ID`،
   `node_modules\next\package.json`) تأیید می‌شود؛ فایل نصب هم باید هدر معتبر PE (`MZ`) و حجم منطقی داشته باشد.
   نتیجه‌ی آخرین ساخت: `portable zip: ok (11046 entries)` و `setup exe: ok (PE header, 87.1 MB)`.
5. **چک‌سام SHA256** همه‌ی خروجی‌ها + ثبت گزارش ساخت (`BUILD-REPORT.txt`) — همین گزارش در
   یادداشت‌های انتشار هم می‌آید تا پیش از دانلود قابل بررسی باشد.

آخرین گزارش ساخت (نسخه‌ی 1.0.0): Node.js **v24.21.0** · yt-dlp **2026.08.19** ·
ffmpeg **N-92722-gf22fcd4483** · حجم نصب‌شده **۳۶۳.۳ مگابایت**.
